# PrinterOne Roadmap

Этот документ описывает ближайшие технические приоритеты проекта. Планы могут
меняться по результатам тестирования на реальном оборудовании и обратной связи.

## v1.0.2 — надёжность и диагностика

### Windows Print Spooler

- различать успешные, окончательные и временные состояния заданий;
- продолжать наблюдение при отсутствии бумаги, offline-состоянии и необходимости
  вмешательства пользователя;
- корректно завершать наблюдение по успеху, удалению задания или таймауту;
- не повторять одинаковые сообщения о состоянии в журнале;
- сохранить гарантированную очистку ресурсов при ошибках Winspool.

### Конфигурация и параллельная работа

- привязать каждое принятое задание к снимку конфигурации на момент подключения;
- исключить отправку уже принимаемого задания на другой принтер после изменения
  настроек;
- проверить доступ к runtime-конфигурации с помощью Go race detector.

### Большие RAW-задания

- определять формат только по небольшой начальной части потока;
- не создавать копию всего задания ради диагностического анализа;
- сохранить распознавание PDF, PostScript, PJL/PCL, Canon UFR II, ZPL, TSPL,
  ESC/POS и XPS;
- никогда не блокировать печать из-за невозможности определить формат.

### Журналы

- автоматически удалять устаревшие файлы журнала;
- ограничить общее количество сохранённых журналов;
- не записывать содержимое печатных заданий.

### Тестирование

- расширить тесты частичной и нулевой записи Winspool;
- проверить смену конфигурации во время приёма задания;
- покрыть временные и окончательные статусы spooler;
- проверить таймаут наблюдения без зависших goroutine;
- выполнять `go test`, `go test -race`, `go vet` и Windows production build
  перед выпуском.

## Принципы совместимости

Новые изменения не должны нарушать подтверждённый production-сценарий:

```text
TCP client → PrinterOne → Windows Print Spooler → USB/network printer
```

Формат конфигурации, RAW-протокол, порт по умолчанию и существующий интерфейс
должны оставаться совместимыми с `v1.0.1`. Рабочий USB-сценарий проверен на
Canon MF4550; совместимость с Zebra, TSC и ESC/POS-оборудованием должна
сохраняться.
